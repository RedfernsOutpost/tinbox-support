# The Homebrew Shelf

The catalogue behind Tinbox's **Library › Shelf** tab: free homebrew for Game Boy,
Game Boy Color and Game Boy Advance that players browse inside the app and add
with one tap. The app fetches `catalog.json` from this folder at run time, so
the Shelf grows without an app update.

## Inclusion rule

A title is listed only when its licence text, or a written statement from the
author, permits redistribution of the compiled ROM. MIT, BSD, zlib, ISC,
CC BY, CC BY-SA, CC0, GPL, LGPL, AGPL and MPL qualify. "Free to play" or
"name your price" with no licence does not, shareware does not, NonCommercial
or NoDerivs Creative Commons terms do not (an app store listing is a commercial
context), and nothing that uses Nintendo or other third-party characters,
names or assets is ever listed. ROM hacks are never listed. The evidence for
every entry, and the titles that were checked and held back, are in
[SOURCES.md](SOURCES.md).

## Files

| Path | What |
|---|---|
| `titles.json` | Hand-maintained source of truth: everything except `sha256` and `size`. |
| `catalog.json` | Generated by `tools/build_catalog.py`; what the app downloads. |
| `covers/<id>.png` | 600×600 covers rendered by `tools/make_covers.py` in the Tin style. |
| `LICENSES/<id>.txt` | The verbatim licence text of each title, shown in the app. |
| `roms/<id>.<ext>` | Mirrors, only where the licence permits and no stable author URL exists. |
| `SOURCES.md` | Evidence table (licence file URL, release URL) and the "needs permission" list. |

## catalog.json schema

```json
{
  "version": 1,
  "updated": "2026-11-15",
  "titles": [
    {
      "id": "feline",
      "title": "Feline",
      "author": "Jono Shields",
      "system": "gba",
      "year": 2021,
      "blurb": "One or two plain sentences.",
      "licence": "MIT",
      "licenceURL": "https://raw.githubusercontent.com/.../LICENSE",
      "sourceURL": "https://github.com/...",
      "downloadURL": "https://github.com/.../releases/download/.../feline-88.gba",
      "sha256": "…64 hex…",
      "size": 1441792,
      "cover": "covers/feline.png",
      "licenceFile": "LICENSES/feline.txt",
      "fileName": "Feline.gba",
      "tags": ["platformer", "adventure"]
    }
  ]
}
```

- `system` is `gb`, `gbc` or `gba`.
- `licence` is the short label the app shows; `licenceFile` is the full text it
  shows when tapped; `licenceURL` is where that text lives upstream.
- `fileName` is what the ROM is called in the player's library. The four
  starter games Tinbox preinstalls use the same names, so the Shelf shows them
  as already in the tin.
- `sha256` and `size` describe the exact file at `downloadURL`. The app
  refuses a download that does not match, so when an author re-uploads a
  release asset, re-run the builder and commit the new hash.
- `cover` and `licenceFile` are relative to this folder.

## Updating

1. Edit `titles.json` (and drop the licence text into `LICENSES/`).
2. `python shelf/tools/make_covers.py <id>`
3. `python shelf/tools/build_catalog.py` (downloads, hashes, checks headers, writes `catalog.json`).
4. Add the evidence row to `SOURCES.md`, commit, push. The app picks it up within a day.

`python shelf/tools/build_catalog.py --verify` re-downloads everything the
catalogue points at and reports any upstream file that changed.
